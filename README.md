# MediaKit — เว็บบีบอัดวิดีโอ รูปภาพ และแปลงไฟล์ครบวงจร

เว็บแอปสำหรับบีบอัดวิดีโอ บีบอัดรูปภาพ และแปลงไฟล์มีเดียที่ประมวลผลในเบราว์เซอร์ของผู้ใช้ 100% (Client-side WebCodecs + Canvas) **ไม่ต้องอัปโหลดไฟล์ขึ้นเซิร์ฟเวอร์** ปลอดภัยและนำไปโฮสต์บน GitHub Pages / Netlify / Vercel ได้ฟรีทันที

## ✨ เครื่องมือที่ใช้งานได้ครบในเมนู Sidebar
1. **🎬 บีบอัดวิดีโอ (Video Compressor)**
   - รองรับสูงสุด **20 ไฟล์ต่อครั้ง**
   - เลือกวิธีบีบอัดได้ 5 แบบ: กำหนดขนาดไฟล์ (**MB**), เปอร์เซ็นต์ (**%**), คุณภาพ (**Quality**), ความละเอียด (**Resolution**), หรือ **Max Bitrate**
   - เลือก Codec ได้: **H.264 (CPU/GPU)**, **H.265 / HEVC (CPU/GPU)**, **AV1**, **VP9** พร้อมตัวเลือกรองรับอุปกรณ์รุ่นเก่า
   - ปรับความละเอียดได้ทั้งแบบ **Preset (2160p–360p)**, **Scale (%)**, และ **Custom (กว้าง×สูง)**
   - คำนวณ Bitrate อัตโนมัติพร้อมป้ายประเมินคุณภาพและคำแนะนำป้องกันภาพแตก (และบีบรอบ 2 อัตโนมัติหากไฟล์เกินขนาด MB ที่กำหนด)
2. **🔄 แปลงไฟล์วิดีโอ (Video Converter)** — แปลงเป็น MP4, MOV, WebM, MKV
3. **✂️ ตัดวิดีโอ (Video Trimmer)** — กำหนดวินาทีเริ่มต้น-สิ้นสุด (ตั้งแยกแต่ละไฟล์ได้)
4. **🎞️ วิดีโอเป็น GIF (Video to GIF)** — แปลงช่วงคลิปวิดีโอเป็นภาพเคลื่อนไหว GIF ปรับ FPS, ความกว้าง และจำนวนสีได้
5. **🖼️ บีบอัดรูปภาพ (Image Compressor)** — บีบอัดรูปครั้งละ 20 ไฟล์ กำหนดขนาดเป้าหมายเป็น **KB**, **%** หรือระดับคุณภาพ
6. **🔁 แปลงไฟล์รูปภาพ (Image Converter)** — แปลงรูปเป็น WebP, JPG, PNG พร้อมย่อขนาดพิกเซล
7. **🎵 แยกเสียงจากวิดีโอ (Audio Extractor)** — ดึงเสียงออกเป็นไฟล์ MP3, M4A, WAV หรือ OGG

## 📦 ฟีเจอร์จัดการไฟล์และดาวน์โหลด
- ตั้งชื่อไฟล์แยกแต่ละไฟล์ หรือตั้งชื่อพร้อมกันทั้งหมดด้วยตัวแปร `{name}`, `{n}`, `{date}`, `{size}`
- เลือกติ๊กถูกว่าจะดาวน์โหลดเฉพาะบางไฟล์ (**Download Selected**) หรือดาวน์โหลดทั้งหมด (**Download All**)
- สวิตช์เลือกได้ว่าจะ **รวมเป็นไฟล์ `.zip`** (ตั้งชื่อไฟล์ ZIP ได้) หรือดาวน์โหลดแยกทีละไฟล์
- มีปุ่ม **✨ ทดลองสร้างไฟล์ตัวอย่าง** บนหน้าเว็บเพื่อทดสอบระบบได้ทันทีแม้ยังไม่มีไฟล์ในเครื่อง
- รองรับทั้งหน้าจอ **Desktop** และ **Mobile**

## 🚀 วิธีรันในเครื่อง (Local)
```bash
python3 -m http.server 8080
```
แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:8080`

## 🌐 วิธีอัปโหลดขึ้น GitHub และเปิดใช้งานเว็บฟรี (GitHub Pages)
โปรเจกต์นี้ตั้งค่า Git (`main`) และ GitHub Actions (`.github/workflows/deploy.yml`) ไว้ให้พร้อมแล้ว:

1. สร้าง Repository ใหม่บน GitHub (เช่น `mediakit-web`)
2. รันคำสั่งในโฟลเดอร์โปรเจกต์เพื่ออัปขึ้น GitHub:
   ```bash
   git remote add origin https://github.com/mstackhub/beebfile.git
   git push -u origin main
   ```
3. ไปที่หน้า GitHub Repository → **Settings** → **Pages** → หัวข้อ **Build and deployment (Source)** เลือกเป็น **GitHub Actions** (หรือ **Deploy from a branch** → `main` / `/ (root)`)
4. รอประมาณ 1 นาที เว็บไซต์ของคุณจะออนไลน์ผ่าน `https://mstackhub.github.io/beebfile/` ทันที!
