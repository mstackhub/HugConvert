# HugConvert — เว็บบีบอัดวิดีโอ รูปภาพ แก้ไขไฟล์ PDF และแปลงไฟล์ครบวงจร

เว็บแอปสำหรับบีบอัดวิดีโอ บีบอัดรูปภาพ **แก้ไขและจัดการไฟล์ PDF** รวมถึงแปลงไฟล์มีเดียที่ประมวลผลในเบราว์เซอร์ของผู้ใช้ 100% (Client-side WebCodecs + PDF-lib + PDF.js + Canvas) **ไม่ต้องอัปโหลดไฟล์ขึ้นเซิร์ฟเวอร์** ปลอดภัยและนำไปโฮสต์บน GitHub Pages / Netlify / Vercel ได้ฟรีทันที

## ✨ เครื่องมือที่ใช้งานได้ครบทั้ง 12 เมนูใน Sidebar

### 🎬 หมวดวิดีโอ (Video)
1. **🎬 บีบอัดวิดีโอ (Video Compressor)**
   - รองรับสูงสุด **20 ไฟล์ต่อครั้ง**
   - เลือกวิธีบีบอัดได้ 5 แบบ: กำหนดขนาดไฟล์ (**MB**), เปอร์เซ็นต์ (**%**), คุณภาพ (**Quality**), ความละเอียด (**Resolution**), หรือ **Max Bitrate**
   - เลือก Codec ได้: **H.264 (CPU/GPU)**, **H.265 / HEVC (CPU/GPU)**, **AV1**, **VP9** พร้อมตัวเลือกรองรับอุปกรณ์รุ่นเก่า
   - ปรับความละเอียดได้ทั้งแบบ **Preset (2160p–360p)**, **Scale (%)**, และ **Custom (กว้าง×สูง)**
2. **🔄 แปลงไฟล์วิดีโอ (Video Converter)** — แปลงเป็น MP4, MOV, WebM, MKV
3. **✂️ ตัดวิดีโอ (Video Trimmer)** — กำหนดวินาทีเริ่มต้น-สิ้นสุด (ตั้งแยกแต่ละไฟล์ได้)
4. **🎞️ วิดีโอเป็น GIF (Video to GIF)** — แปลงช่วงคลิปวิดีโอเป็นภาพเคลื่อนไหว GIF ปรับ FPS, ความกว้าง และจำนวนสีได้

### 🖼️ หมวดรูปภาพ (Image)
5. **🖼️ บีบอัดรูปภาพ (Image Compressor)** — บีบอัดรูปครั้งละ 20 ไฟล์ กำหนดขนาดเป้าหมายเป็น **KB**, **%** หรือระดับคุณภาพ
6. **🔁 แปลงไฟล์รูปภาพ (Image Converter)** — แปลงรูปเป็น WebP, JPG, PNG พร้อมย่อขนาดพิกเซล

### 📄 หมวดเอกสาร (PDF Toolkit ครบชุด)
7. **✏️ แก้ไขไฟล์ PDF (Visual PDF Editor & Annotator)**
   - เปิดดูหน้าเอกสารบนกระดาษโต้ตอบ (Interactive Stage) พร้อมแถบหน้าย่อ
   - **🔤 เพิ่มข้อความ** (รองรับภาษาไทย 100% เลือกสีและขนาดตัวอักษร ลากย้ายตำแหน่งหรือดับเบิลคลิกแก้ไขข้อความได้)
   - **✏️ ปากกาวาด & 🖍️ ไฮไลต์** วาดเขียนอิสระลงบนหน้าเอกสาร
   - **✍️ เซ็นลายเซ็น (Signature Pad)** วาดลายเซ็นบนกระดานแล้วนำไปวางและย่อขยายบนเอกสาร
   - **🖼️ แทรกรูปภาพ / ตราประทับ** และ **⬜ ลบคำผิด/กล่องสีขาวปิดทับข้อความเดิม**
   - **↺ ↻ หมุนหน้าซ้าย-ขวา**, **↑ ↓ เลื่อนสลับลำดับหน้า**, และ **🗑️ ลบหน้าที่ไม่ต้องการ**
8. **📉 บีบอัดไฟล์ PDF (Compress PDF)** — ลดขนาดไฟล์ PDF ครั้งละ 20 ไฟล์ กำหนดขนาดเป้าหมายเป็น **MB**, **%**, หรือระดับความคมชัด พร้อมโหมดขาว-ดำ (Grayscale)
9. **📑 รวม & แยกหน้า PDF (Merge & Split PDF)** — รวมหลายไฟล์ PDF เป็นเล่มเดียว หรือระบุช่วงหน้าที่จะแยก เช่น `1-3, 5`
10. **📸 PDF เป็นรูปภาพ (PDF to Image)** — แปลงหน้า PDF เป็นไฟล์รูป JPG, PNG หรือ WebP ความละเอียดสูง (150–300 DPI)
11. **📄 รูปภาพเป็น PDF (Image to PDF)** — รวมรูปภาพหลายๆ รูปเป็นไฟล์ PDF เล่มเดียว (เลือกขนาดกระดาษ A4 / Fit to Image / แนวตั้ง-แนวนอนได้)

### 🎵 หมวดเสียง (Audio)
12. **🎵 แยกเสียงจากวิดีโอ (Audio Extractor)** — ดึงเสียงออกเป็นไฟล์ MP3, M4A, WAV หรือ OGG

## 📦 ฟีเจอร์จัดการไฟล์และดาวน์โหลด
- ตั้งชื่อไฟล์แยกแต่ละไฟล์ หรือตั้งชื่อพร้อมกันทั้งหมดด้วยตัวแปร `{name}`, `{n}`, `{date}`, `{size}`
- เลือกติ๊กถูกว่าจะดาวน์โหลดเฉพาะบางไฟล์ (**Download Selected**) หรือดาวน์โหลดทั้งหมด (**Download All**)
- สวิตช์เลือกได้ว่าจะ **รวมเป็นไฟล์ `.zip`** (ตั้งชื่อไฟล์ ZIP ได้) หรือดาวน์โหลดแยกทีละไฟล์
- มีปุ่ม **✨ ทดลองสร้างไฟล์ตัวอย่าง** (สร้างวิดีโอ, รูปภาพ หรือ PDF ตัวอย่างได้ในคลิกเดียว)

## 🚀 วิธีรันในเครื่อง (Local)
```bash
python3 -m http.server 8080
```
แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:8080`
